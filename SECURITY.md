# Security and privacy

Use GitHub’s private vulnerability reporting on this repository for security issues. Do not post ADB keys, active pairing QR codes, pairing codes, or unredacted device logs in public issues.

The initial release is ad-hoc signed and not notarized. Review source before running it. Pairing authorizes your Mac for Android debugging. Only pair phones you own or are authorized to debug and revoke trust from Android’s Wireless debugging settings when no longer needed.

The app uses the existing local ADB server. Its owner’s macOS Local Network permission affects network access. The app does not disable firewalls or bypass macOS permissions.
